Calendar Blockify

Share your availability without revealing event details. All busy blocks simply show as Unavailable.

Google Cloud Setup Instructions
1

Create a Google Cloud Project

Go to Google Cloud Console and create a new project (or select an existing one).

2

Enable Google Calendar API

Navigate to APIs & Services → Library, search for "Google Calendar API" and click Enable.

3

Configure OAuth Consent Screen

Go to APIs & Services → OAuth consent screen. Choose External (or Internal for Workspace), fill in the required app name and email fields. Add your email as a test user.

4

Create OAuth Client ID

Go to APIs & Services → Credentials → Create Credentials → OAuth client ID. Select Web application.

5

Add Authorized JavaScript Origins

http://localhost:5173
http://localhost:8000
http://127.0.0.1:5500
6

Copy Your Client ID

Paste it in the input field below or in app.js at CLIENT_ID.

Run via local server

Don't open the HTML file directly. Use one of these:

python3 -m http.server 8000

npx serve
